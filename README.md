# Openshop — অ্যাডমিন-নিয়ন্ত্রিত ই-কমার্স ওয়েবসাইট

## 🔧 এই ভার্সনে যা ঠিক করা হয়েছে
0. **(নতুন) ফেসবুক ক্যাপশন + অটো কুপন জেনারেটর** — এডমিন প্যানেলের "প্রোডাক্ট" ট্যাবের নিচে নতুন কার্ড "📢 ফেসবুক ক্যাপশন ও অটো কুপন জেনারেটর"। একটা প্রোডাক্ট বাছুন, "✨ ক্যাপশন ও কুপন তৈরি করুন" চাপুন — প্রোডাক্টের নাম, দাম, ছাড়, ভ্যারিয়েন্ট, বিবরণ ও স্টক-স্ট্যাটাস দেখে ইমোজিসহ একটা রেডি ফেসবুক পোস্ট ক্যাপশন তৈরি হবে (কপি বাটন দেওয়া আছে), আর সাথে সাথে ওই প্রোডাক্টের জন্য একটা ইউনিক কুপন কোড অটো-জেনারেট হয়ে সরাসরি "কুপন ম্যানেজমেন্ট"-এ সেভ হয়ে যাবে (ছাড়ের % প্রোডাক্টের ক্রয়মূল্য থাকলে সেটা দেখে নিরাপদভাবে হিসাব হয়, না থাকলে ডিফল্ট ১০%)। "🔄 নতুন কোড দিয়ে আবার তৈরি করুন" চাপলে নতুন কোড ও ক্যাপশন তৈরি হবে।
0. **(নতুন) অর্ডার WhatsApp-এ যাচ্ছিল না** — কারণ ছিল: চেকআউট ক্লিকের পর WhatsApp খোলার আগে Firestore সেভ/ছবি fetch-এর মতো async কাজ চলছিল, যার ফলে ব্রাউজার ক্লিকটাকে আর "ইউজারের অ্যাকশন" ধরছিল না ও WhatsApp খোলা ব্লক করে দিচ্ছিল। এখন ক্লিক করা মাত্রই সবার আগে (কোনো await ছাড়াই) WhatsApp চ্যাট খোলে, বাকি সব কাজ পরে ব্যাকগ্রাউন্ডে হয়।
0. **(নতুন) অর্ডার আইডি কপি করা যাচ্ছিল না** — আগে সাধারণ `alert()`-এ অর্ডার আইডি দেখানো হতো, যেটা মোবাইলে সিলেক্ট/কপি করা যায় না। এখন একটা নতুন কনফার্মেশন পপআপ আছে, যেখানে অর্ডার আইডি একটা "কপি করুন" বাটনসহ দেখানো হয়, আর "WhatsApp আবার খুলুন" ও "ছবিসহ শেয়ার করুন" বাটনও আছে।
1. **"Missing or insufficient permissions" এরর** — এটা কোডের বাগ ছিল না, Firestore-এর ডিফল্ট লকড রুলের কারণে হচ্ছিল। ফিক্স: নিচের দেওয়া **`firestore.rules`** ফাইলের কন্টেন্ট Firebase Console → Firestore Database → Rules-এ বসিয়ে Publish করুন (নিচে "Firestore Rules" সেকশনেও বিস্তারিত আছে)।
2. **একসাথে একাধিক ছবি বাছাই** — এডমিন প্যানেলে প্রোডাক্ট যোগ/এডিট করার সময় এখন গ্যালারি থেকে একসাথে একাধিক ছবি বাছা যাবে, সবগুলো অটো আপলোড হয়ে থাম্বনেইল গ্রিডে দেখাবে (× চেপে বাদও দেওয়া যাবে, প্রথমটা কভার ছবি হিসেবে ব্যবহার হয়)।
3. **অর্ডার প্লেস করলে ছবিসহ WhatsApp-এ পাঠানো** — চেকআউট করলে এখন মোবাইলে ব্রাউজারের নেটিভ শেয়ার শিট খুলবে, যেখান থেকে WhatsApp বেছে নিলে প্রোডাক্টের আসল ছবিসহ অর্ডার মেসেজ চলে যাবে। শেয়ার সাপোর্ট না থাকলে (যেমন কম্পিউটার থেকে) আগের মতো WhatsApp চ্যাট খুলবে, তবে মেসেজে প্রতিটা প্রোডাক্টের ছবির লিংকও যোগ করা থাকবে।
4. **ফ্লোটিং WhatsApp বাটন সিঙ্ক** — আগে সাইট সেটিংস এখনো একবারও সেভ না করা থাকলে ফ্লোটিং বাটনটা কাজ করত না (href = "#" থেকে যেত)। এখন এটা লোড হওয়া মাত্রই ডিফল্ট নম্বর দিয়ে সিঙ্ক হয়ে যায়, সেটিংস সেভ করলে সেই নম্বর দিয়ে আপডেট হয়ে যায়।


একটা সম্পূর্ণ অনলাইন শপ, যেখানে **অ্যাডমিন প্যানেল থেকে সব কিছু নিয়ন্ত্রণ করা যায়** — প্রোডাক্ট, অফার/ছাড়, সাইটের রং-লোগো-ব্যানার, আর প্রতিটা অর্ডারের ট্র্যাকিং স্ট্যাটাস।

- বাকি সব (প্রোডাক্ট ম্যানেজমেন্ট, অ্যানালিটিক্স, গ্যালারি থেকে ছবি আপলোড, হোম-স্ক্রিন অ্যাপ ইনস্টল) আগের মতোই আছে

## ফাইল স্ট্রাকচার
- `index.html`, `style.css`, `script.js` — মূল ওয়েবসাইট
- `admin.html` — এডমিন ড্যাশবোর্ড (৫ ট্যাব: অ্যানালিটিক্স, প্রোডাক্ট, অর্ডার ও ট্র্যাকিং, সাইট সেটিংস, গ্রাহক তালিকা)
- `products.js` — Firebase কনফিগার না থাকলে ব্যবহৃত হবে এমন স্ট্যাটিক প্রোডাক্ট তালিকা
- `firebase-config.js` — Firebase কানেকশনের তথ্য
- `manifest.json`, `admin-manifest.json`, `sw.js` — হোম স্ক্রিনে অ্যাপ হিসেবে বসানোর জন্য
- `firestore.rules` — Firebase Console-এ কপি-পেস্ট করার জন্য (নিচের "Firestore Rules" সেকশন দেখুন)
- `images/` — লোগো, হিরো ব্যাকগ্রাউন্ড, ও প্রোডাক্ট ছবি

## GitHub-এ আপলোড করার নিয়ম
1. এই zip এক্সট্র্যাক্ট করুন
2. GitHub Repository-এর সব পুরনো ফাইল ডিলিট করুন
3. নতুন সব ফাইল ও `images` ফোল্ডার আপলোড করুন এবং Commit করুন
4. নিচের Firestore Rules বসান (নতুন `orders` কালেকশনের জন্য দরকার)

## Firestore Rules (আপডেট করুন) — "Missing or insufficient permissions" এররের সমাধান
⚠️ **এই ভার্সনে নতুন `likes` কালেকশন যোগ হয়েছে (প্রোডাক্ট লাইক ফিচারের জন্য) — তাই নিচের রুলগুলো আবার Publish করতে হবে, নাহলে লাইক ফিচারটা কাজ করবে না।**
এই zip-এ থাকা `firestore.rules` ফাইলটা খুলে পুরো কন্টেন্ট কপি করুন, অথবা নিচেরটা কপি করুন। তারপর:
Firebase Console → Firestore Database → Rules:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /settings/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /events/{doc}   { allow read: if request.auth != null; allow create: if true; }
    match /leads/{doc}    { allow read: if request.auth != null; allow create: if true; }
    match /orders/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
    match /coupons/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /reviews/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
    match /likes/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
  }
}
```

## কুপন সিস্টেম (নতুন — একাধিক কুপন সাপোর্ট করে)
অ্যাডমিন → সাইট সেটিংস ট্যাবে "🏷️ কুপন ম্যানেজমেন্ট" কার্ড থেকে একসাথে একাধিক কুপন যোগ করা যাবে। প্রতিটা কুপনে আলাদাভাবে সেট করা যাবে:
- **ছাড়ের ধরন:** শতাংশ (%) অথবা নির্দিষ্ট টাকা (৳)
- **সর্বনিম্ন অর্ডার:** এর কম হলে কুপন কাজ করবে না
- **সর্বোচ্চ ব্যবহার সীমা:** কতবার ব্যবহার হলে কুপনটা বন্ধ হয়ে যাবে (খালি রাখলে সীমাহীন)
- **মেয়াদ শেষের তারিখ:** এই তারিখের পর কুপন আর কাজ করবে না
- **চালু/বন্ধ টগল:** এক ক্লিকে কুপন সাময়িকভাবে বন্ধ/চালু করা যাবে, ডিলিট না করেই

কাস্টমার চেকআউটের সময় কোড লিখে "প্রয়োগ করুন" চাপলে এই শর্তগুলো Firestore থেকে যাচাই হয়। চেকআউট করার ঠিক আগমুহূর্তেও আরেকবার (দ্রুত, সিঙ্ক্রোনাসভাবে) যাচাই হয়, যাতে অ্যাডমিন কুপন বন্ধ করে দিলে পুরনো ছাড় প্রয়োগ না হয়ে যায়।

## প্রোডাক্ট রিভিউ ও রেটিং (নতুন)
প্রোডাক্ট মডালে কাস্টমাররা স্টার রেটিং (১-৫) ও মন্তব্য দিয়ে রিভিউ দিতে পারবেন — নাম দেওয়া ঐচ্ছিক। গড় রেটিং প্রোডাক্ট কার্ড ও মডাল দুই জায়গাতেই দেখা যাবে। অ্যাডমিন প্যানেলের "⭐ রিভিউ" ট্যাব থেকে অনুপযুক্ত/ভুয়া রিভিউ মুছে ফেলা যাবে।

## প্রোডাক্ট ফিল্টার (নতুন)
প্রোডাক্ট সেকশনের "🔎 ফিল্টার" বাটনে চাপলে দামের রেঞ্জ (সর্বনিম্ন-সর্বোচ্চ) ও ন্যূনতম রেটিং দিয়ে প্রোডাক্ট ফিল্টার করা যাবে। সার্চ এখন প্রোডাক্টের বিবরণেও খুঁজবে (আগে শুধু নাম/ক্যাটাগরিতে খুঁজত)।

## অর্ডার ট্র্যাকিং কীভাবে কাজ করে
1. কাস্টমার কার্ট থেকে চেকআউট করলে নাম, ফোন (বাধ্যতামূলক), ঠিকানা দেন
2. একটা অর্ডার আইডি তৈরি হয় ও Firestore-এর `orders` কালেকশনে সেভ হয় (status: `pending`)
3. একই সাথে হোয়াটসঅ্যাপে অর্ডার আইডিসহ মেসেজ চলে যায়
4. অ্যাডমিন প্যানেলের "অর্ডার ও ট্র্যাকিং" ট্যাব থেকে স্ট্যাটাস বদলে দিলে কাস্টমার নিজের ফোন নম্বর বা অর্ডার আইডি দিয়ে "প্রোফাইল" থেকে দেখতে পারবেন

অ্যাডমিন → সাইট সেটিংস ট্যাবের সবচেয়ে উপরে "থিম রং ও অফার ব্যানার" কার্ড থেকে প্রধান রং, এক্সেন্ট রং, ও অফার ব্যানারের লেখা বদলে সেভ করুন।
